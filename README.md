# متابع التمرين والتغذية (Mutabei Workout & Nutrition)

تطبيق أندرويد أصلي مكتوب بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** مع دعم كامل للغة العربية (RTL) والثيم الفاتح والداكن.

## الميزات الرئيسية
- **التمرين (12 أسبوع — جدول البالغامدي 5 أيام + جداول مخصصة):**
  - متابعة الأوزان والعدات وحساب `e1RM` وتنبيهات الأرقام القياسية (PR) والثبات (Plateau).
  - حاسبة مجموعات التسخين، خرائط العضلات، روابط شرح يوتيوب، تبديل التمارين البديلة، ورسوم بيانية للتقدم.
  - مؤقت راحة عائم بحلقة دائرية مع اهتزاز وصوت تنبيه.
- **التغذية والميكرونيوترينتس:**
  - قاعدة بيانات مدمجة تحتوي على **12,613 أكلة** (مصرية + USDA) مع بحث ذكي بالعامية المصرية وتصحيح الإملاء.
  - تتبع 4 وجبات + الماء + أهداف السعرات والماكروز (Katch-McArdle / Mifflin-St Jeor).
  - حاسبة الوصفات المنزلية بعوامل الاحتفاظ الغذائي (USDA Release 6)، الميكرونيوترينتس اليومية ومتوسط 7 أيام مع اقتراحات أكلات لعلاج النقص، والمراجعة الأسبوعية.
- **ميزات الكاميرا والملء التلقائي عبر Gemini (Firebase AI Logic):**
  - تصوير ورقة الـ **InBody** وملء كافة الخانات تلقائيًا مع فحص التناسق الرياضي.
  - تصوير **ملصق القيم الغذائية** للمنتجات وتحويله تلقائيًا لقيم لكل 100 جم.
  - تصوير **الوجبة** أو **وصفها بالنص** لتحديد الأصناف وتقدير الجرامات ومطابقتها بقاعدة البيانات.
  - مسح **الباركود** بالكاميرا عبر Gemini والبحث في Open Food Facts مع حفظ المنتج تلقائيًا.
- **المزامنة السحابية والأمان:**
  - تسجيل الدخول بحساب Google عبر Jetpack Credential Manager وحفظ كافة البيانات سحابيًا في Firebase Firestore مع قواعد أمان معزولة لكل مستخدم، بالإضافة لدعم التصدير والاستيراد بصيغة JSON.
